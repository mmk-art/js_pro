# Quick Start Guide

## 🚀 Get Started in 3 Steps

### 1. Install Dependencies
```bash
npm install
```

### 2. Start the App
```bash
npm start
# or
expo start
```

### 3. Run on Your Device
- **Android**: Press `a` or scan QR code with Expo Go app
- **iOS**: Press `i` or scan QR code with Expo Go app
- **Web**: Press `w` for web version

## 🎯 First Time Setup

1. **Load Demo Data**: Tap "Load Demo Data" button on the home screen
2. **Explore**: Navigate through the demo trips and expenses
3. **Create Your Own**: Use the + button to add new trips and expenses

## 📱 App Features

- **Home Screen**: Overview of all trips and total budget
- **Trip Details**: View expenses by category with horizontal tabs
- **Add Expenses**: Modal form with amount, category, and friend selection
- **Friend Summary**: Individual spending breakdowns and category analysis
- **Offline Storage**: All data saved locally using AsyncStorage

## 🔧 Troubleshooting

- **Metro bundler issues**: Try `npm start --reset-cache`
- **Dependencies**: Run `npx expo install --fix` to fix version mismatches
- **Device not connecting**: Make sure Expo Go app is installed and updated
